# Decompas - Consultor de IA y Diseño para Pymes

Landing page para Daniel Rojas, consultor de IA y diseño para Pymes en Cali, Colombia.

## Servicios

- Agentes de atención y ventas con IA
- Automatización de procesos
- Diseño con identidad propia

## Desarrollo

```bash
# Instalar dependencias
pip install -r requirements.txt

# Ejecutar localmente
python -m http.server 8000
```

## Despliegue

El sitio se despliega automáticamente en Netlify al hacer push a la rama main.

## Estructura

```
decompas/
├── index.html          # Página principal
├── favicon.svg         # Icono del sitio
├── tokens/             # Configuración de tokens
│   └── theme.json      # Tema de colores
└── README.md           # Este archivo
```
