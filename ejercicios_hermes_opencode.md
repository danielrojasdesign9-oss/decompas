# Ejercicios: Hermes + OpenCode

## Ejercicio 1: Investigación de Mercado
**Objetivo:** Encontrar negocios en Cali que necesiten automatización.

**Pasos:**
1. En Discord escribe: `!opencode investiga 5 restaurantes en Cali que no tengan presencia digital fuerte`
2. OpenCode te dará una lista con nombres, direcciones y qué les falta
3. Usa esa lista para contactarlos

**Resultado:** Lista de prospectos lista para contactar.

---

## Ejercicio 2: Propuesta Personalizada
**Objetivo:** Crear una propuesta para un negocio específico.

## Consejos para usar Hermes + OpenCode

1. **Sé específico:** Cuanto más detalle des, mejor será la respuesta
2. **Pide formatos:** Pide PDFs, listas, tablas, emails formateados
3. **Itera:** Si no te gusta la primera respuesta, pide ajustes
4. **Guarda lo que funcione:** Crea una librería de prompts que te funcionen
5. **Usa ambos:** Hermes para preguntas rápidas, OpenCode para tareas complejas
